No script yet? Set one up in about 10 minutes
  1. Create a Google SheetAny name. Leave it empty.
    Open sheets.new ↗
  2. Open the script editorIn the Sheet: Extensions → Apps Script. Delete the sample code there.
  3. Paste the Gifter scriptCopy it with the button, then paste it into the editor.
  4. Set your passcodeNear the top, change CHANGE-ME to a passcode of your own. Save.
  5. Deploy as a web appDeploy → New deployment → Web app. Execute as Me, access Anyone. Your passcode is what keeps others out.
  6. Allow itGoogle warns “Google hasn’t verified this app”. That is normal — it is your own script, run only by you. Choose Advanced → Go to project → Allow.
  7. Copy the web app URLIt ends in /exec. Paste it into the form, with your passcode.
